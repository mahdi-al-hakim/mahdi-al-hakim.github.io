netcdf-c: integer overflow in classic-format length arithmetic

Mahdi Alhakim

Reported to the vendor on 2026-07-25. The fix, PR #3421, was opened publicly on 2026-07-28 at the maintainer's request and merged on 2026-11-10. It changes two length computations in the classic-format code, libsrc/ncx.h and libsrc/v1hpg.c, so they no longer wrap. There is no CVE.

No netcdf-c release includes the fix yet; the latest release, v4.10.1, predates it. The full writeup, which covers how the overflow was isolated and why the project's only fuzz harness could not reach it, will be published here after a release that carries the fix. Until then this page says only what the public pull request already does.
