Projects

Warden runs a Claude agent on an IT offboarding task under policy, human approval, a hash-chained audit log, and a revocation kill switch, and reads the systems back at the end of each run. It replays an authored script by default and drives a Claude model in live mode. In an eval on Claude Haiku, Sonnet and Opus 5.5, a note planted in the departing contractor's directory record asked the agent to also disable a shared admin account, and none of 30 live runs acted on it. No arm made that write the right call, so it can't show a model refusing it, and ten runs per model still allows a rate of up to about one in four.

controlarm is the public core of the harness I use for vulnerability research. It will not record a security test as negative unless the same run shows the target answering and the plain version of the attack being refused, so a run whose rig never worked is filed VOID instead of clean. Whether a test's own probe can see a success is still up to whoever wrote it. Its prior-art check queries OSV, GHSA and NVD and is scored against 80 labeled items from 40 advisories, and CI removes each of its 188 guards to show a test catches the removal.

malt-reward-hacking checks monitor scores on METR's MALT dataset against the simplest baseline I could find. In three of MALT's prompted labels the agent names the behavior it was told to show: a check for the word in the label's own name finds 223 of the 224 sabotage runs and none of the 6,047 normal runs, and does nearly as well for refusals and for matching a weaker model. So a monitor's score on those labels can't show it finds sabotage an agent keeps quiet about. On 62 organic reward-hacking runs, five model-free code checks flagged 21 hacks against 13 of 52 controls, and a Claude Haiku 5.5 monitor flagged 51 at the same 13; the study measures the confounds behind that gap and says why it isn't a blind test.

Writeups

One method of one tool: an incomplete content filter in github-mcp-server lockdown mode

pull_request_read dispatches nine methods from one switch. Seven of them return text written by repository users, and lockdown mode covered six. The writeup covers the two-account rig, the positive control that proved the gap at runtime, and how GitHub's description of lockdown (a best-effort content filter) settled whether this counted as a gap.

Reported Aug 2026. Fixed in v1.10.0 the same month; one of three credited reporters.

netcdf-c: integer overflow in classic-format length arithmetic

netcdf-c runs on OSS-Fuzz, and its only fuzz harness opened a file and closed it without ever reading an attribute, so an overflow in the classic-format length arithmetic sat out of its reach.

Reported Jul 2026. My fix merged Nov 2026. The full writeup follows the first release that includes it.
