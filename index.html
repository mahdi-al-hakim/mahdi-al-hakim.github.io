A prompt-injection filter covered six of the seven methods that needed it. A fuzz harness opened the file and closed it again without ever reading an attribute. An admin screen reported no access while the write went through. A safety probe passed green while the agent sent data out on every turn. Four different codebases, one failure: the thing meant to catch the problem could not have seen it.

Writeups

Each of these went to the vendor privately first. Each one covers how the gap was found and how it was proven, not just what it was.

One method of one tool: an incomplete content filter in github-mcp-server lockdown mode

pull_request_read dispatches nine methods from one switch. Seven of them return text written by repository users, and lockdown mode covered six. The writeup covers the two-account rig and the positive control that proved it at runtime rather than from reading the source, and how the trust model the vendor actually ships, a best-effort content filter and not an authorization boundary, decides what counts as a gap at all.

Reported Aug 2026, fixed in v1.10.0 the same month. One of three credited reporters.

A one-byte differential in netcdf-c: integer overflow in classic-format length arithmetic

netcdf-c runs on OSS-Fuzz, and the only harness it had opened a file and closed it without ever reading an attribute value. One byte of an 80-byte header undersizes a heap allocation while the un-wrapped element count still drives the read loop. The writeup covers how the differential was isolated to one byte and why the project's only fuzz harness could never reach it.

Reported Jul 2026. Fix PR open at the maintainer's request. How to build a triggering file is not published here.

All three were accepted, made public by Keycloak staff, and credited by name. One was fixed and backported, one reclassified as an enhancement, one handled publicly as a hardening improvement. The writeup is about what separated them, and about how to write a severity argument.

Tools

controlarm is a harness that refuses to call a security test negative unless the rig was shown to work. A run whose positive control never fired is recorded as VOID instead of "no bug found". Its prior-art gate is scored against 80 labelled items drawn from three public advisory corpora, under a rule written before the corpus was built. 1,275 tests, and 180 guards each neutered in CI to prove a test catches its removal.
